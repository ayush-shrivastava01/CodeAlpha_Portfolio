# Personal Portfolio — Ayush Srivastava

A responsive personal portfolio built with HTML, CSS and vanilla JavaScript as part of the CodeAlpha Frontend Development Internship.

## Sections

- Introduction / Hero
- About
- Skills and technologies
- Selected projects
- Education
- Contact

## Features

- Responsive desktop, tablet and mobile layout
- Mobile navigation menu
- Smooth section navigation
- Scroll progress indicator
- Reveal-on-scroll animations
- Project links to GitHub
- Reduced-motion accessibility support

## Technologies

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Project Structure

```text
CodeAlpha_Portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── (place resume.pdf here if you add a resume link)
```

## Run Locally

Open `index.html` in a browser, or use the VS Code Live Server extension. No build tools or package installation are required.

## Before Publishing

Update the following placeholders in `index.html`:
- Replace `YOUR_EMAIL@example.com` with your professional email address.
- Replace the LinkedIn homepage URL with your personal LinkedIn profile URL.
- If you want to share your resume, add a PDF to `assets/` and add a Resume link to the navigation or contact section.
- Review your education dates and project descriptions for accuracy.

## Deployment

This static site can be deployed with GitHub Pages:
1. Push the repository to GitHub.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
